# Focal Registry

An AvertXAI platform baseplate (Electron desktop) generated by `avertxai-mission-control`.

## Run

```
npm install      # rebuilds better-sqlite3 for Electron (postinstall)
npm run dev      # build + launch
npm run build    # production build (must be clean)
npm run package  # electron-builder --win (nsis + portable)
```

## Database

**Local (SQLite).** The shared DB is `focalregistry_{org_id}.db` under the app's userData folder (routed by `platform_registry.db`). Locked modules each open their own `*.locked.db`.

Browse any table from the **Data Viewer** (database icon, top bar) — read-only.

### Module slots

- **GetScriptClips** (`getscriptclips`) — shared
- **Vault** (`vault`) — locked → own DB `vault.locked.db`

## Filling a module slot

Each slot under `src/modules/<slug>/` renders a placeholder. To make it real, replace the
component body and wire data through the main process. The mount points are already in place:

- `src/App.tsx` — import, `View` union member, `LEAF` label, and conditional mount.
- `src/components/Flyout.tsx` — the nav button.

## Standard columns (every table)

Use the `createTable(db, name, columns)` helper in `electron/core/services/db/index.ts`.
Every table is born with:

| column | type |
| --- | --- |
| `id` | `INTEGER PRIMARY KEY` |
| `uuid` | `TEXT UNIQUE NOT NULL` — set it yourself with `import { v7 as uuidv7 } from "uuid"` |
| `created_at` | `DATETIME DEFAULT CURRENT_TIMESTAMP` |
| `updated_at` | `DATETIME` — bump to `CURRENT_TIMESTAMP` on UPDATE |

`getDb()` returns the shared connection; `openDb(path, name)` opens an independent one
(used by Locked modules).
