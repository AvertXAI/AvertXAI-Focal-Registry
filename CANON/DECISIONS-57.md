- **Scan is MEDIA-ONLY.** Only media files get `scan_files` rows. Non-media files are counted and skipped — no row, no metadata call, no error row. On the reference drive that is 36,407 rows instead of 1,289,909.

- **Class-routed BEFORE any parser call:** stills → `exifr`, video → isobmff + `music-metadata`, audio → `music-metadata`. Never hand a parser a format it cannot read.
- **A deliberate skip is NEVER an error row.** Error rows are reserved for a media file we expected to parse that actually failed. Reference drive: 20,173 → 7.
