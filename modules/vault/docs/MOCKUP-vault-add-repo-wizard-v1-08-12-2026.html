A personal access token, stored as a vault entry — recommended One field, pasted once. It becomes a normal encrypted entry you can rotate or revoke like any other credential, and it is read through the same logged path.
Sign in to GitHub A browser login. Friendlier, but it needs a client secret shipped inside the application — which cannot be kept secret in a desktop app — and it only ever works for GitHub.
Not now Track it from disk. You can add a token later without re-adding the repo.
Why the token is the recommendation. An OAuth login needs a client secret inside a shipped desktop app, where anyone can extract it — so it is not really a secret. A token you paste is yours, scoped by you, revocable by you, and it fits the store this app already has. It also works for GitLab, Gitea and anything else with an API, which a GitHub login does not.
