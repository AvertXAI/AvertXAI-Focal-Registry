One editor, three kinds. A note, a runbook and a snippet are the same stored thing — a title, a type and a markdown body. The type changes the icon, the starting template and one toolbar button. Building three editors would mean three places to fix the same bug.

The part that makes it a vault note and not a text file: the orange chip below. A note references a credential by locator; it never contains one. Reveal on the chip is the same logged read as anywhere else, so a runbook can say "use this password" without a password ever being written into a document.

It is a pure function of the fingerprint, which is a pure function of the public key — so the vault keeps the public key and draws the art every time it shows it. Stored derived data drifts from the thing it describes; derived data cannot. The algorithm is the drunken bishop, about forty lines, no dependency and therefore no licence gate.

Everything marked derived below is computed on display and has no column in the database. Everything else is stored exactly like a password — encrypted, versioned, and readable only through a logged read.
